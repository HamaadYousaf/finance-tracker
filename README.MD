# 💰 Finance Tracker

A full-stack personal finance dashboard that lets users track subscriptions, expenses, and monthly spending insights. Built to demonstrate CRUD operations, relational database design, caching with Redis, and modern full-stack integration using Spring Boot and React.

## 🔍 What It Does

- Create and manage recurring subscriptions (Netflix, Spotify, Gym, etc.)
- Track one-time expenses with categories and timestamps
- View a consolidated dashboard of financial activity
- Calculate monthly subscription costs automatically (including yearly normalization)
- Break down spending by category for better financial visibility
- Cache dashboard results for faster response times using Redis
- Multi-user system with authentication support (login/register)

## 🛠️ Technologies

| Layer      | Technology                 |
| ---------- | -------------------------- |
| Frontend   | React (Vite), Tailwind CSS |
| Backend    | Spring Boot                |
| ORM        | Hibernate (JPA)            |
| Database   | PostgreSQL                 |
| Cache      | Redis                      |
| Container  | Docker / Docker Compose    |
| Build Tool | Maven                      |
